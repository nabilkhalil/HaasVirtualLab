# Rules
Each lesson specifies outcomes, initial state, actions, expected final state, hints, common errors and scoring. Include tool length, G54, probing and setup verification. Record accuracy and errors. Require supervised real-machine training.

# Completion
- Check relevant requirements in CLAUDE.md.
- Add or update focused tests.
- Record unresolved assumptions in PROGRESS.md.
